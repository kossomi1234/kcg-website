KCG website - setup
1. Supabase: SQL Editor > paste supabase-setup.sql > Run.
2. Settings > API: copy Project URL and anon key into the CFG block in index.html.
3. Authentication > URL Configuration: set Site URL to your website link.
4. GitHub: upload index.html (replace the old one) > Settings > Pages.
5. Sign up on your site, activate by email, then run the owner line at the bottom of supabase-setup.sql.
6. Optional owner emails: see notify-owner/index.ts.
Languages: English, French, Arabic.
Payment: edit CFG.payments in index.html (number + holder name). Empty ones stay hidden.
Contact: fill email, phone, whatsapp in the CFG block (shown in the Contact section).
Buttons: Search, Help (FAQ), Forgot password, Back to top, floating Help.
Cybersecurity types and services cards are clickable: tap to read more or show less.
